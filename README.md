# RotaJovem

Ferramenta web que auxilia a equipe da externa do EJC na organização das buscas aos encontristas. A partir dos endereços cadastrados, a aplicação calcula prioridades, identifica zonas de maior concentração, sugere agrupamentos por proximidade e estima rotas otimizadas — tudo em uma interface visual com mapa e planilha interativa, apoiando decisões mais rápidas e justas.
